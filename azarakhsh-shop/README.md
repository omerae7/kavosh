# azarakhsh.shop — صفحهٔ نخست فروشگاه آجر نسوز آذرخش

فروشگاه تک‌صفحه‌ای، فارسی و راست‌به‌چپ، با HTML/CSS/JS خالص.
**بدون build step، بدون npm install، بدون اینترنت.** فایل را باز کنید و کار می‌کند.

---

## اجرا

روش ساده (کافی است):

```bash
# داخل همین پوشه
python3 -m http.server 8080
# سپس در مرورگر: http://localhost:8080
```

یا با Node:

```bash
npx serve .
```

> باز کردن مستقیم `index.html` با دابل‌کلیک هم صفحه را نشان می‌دهد، اما بعضی مرورگرها
> روی پروتکل `file://` فونت محلی و `localStorage` را محدود می‌کنند؛ بنابراین اجرای یک
> سرور ساده (دستور بالا) توصیه می‌شود.

## 📷 جای عکس‌ها

تمام تصاویر موجود در `assets/` **موقت و ساختگی** هستند و با اسکریپت
`tools/generate-placeholder-images.py` تولید شده‌اند تا صفحه از همان ابتدا کامل دیده شود.
کافی است هر فایل را با **همان نام** با عکس واقعی جایگزین کنید — هیچ تغییری در کد لازم نیست.

اگر فایلی وجود نداشته باشد، به‌جای تصویر شکسته یک placeholder تمیز نمایش داده می‌شود که
**نام دقیق فایل موردنیاز** را روی خودش نوشته است.

## ویرایش محتوا

همه‌چیز در **`js/data.js`** است و هیچ ابزار خاصی لازم ندارد:

- `PRODUCTS` — نام، کد، قیمت (تومان)، مشخصات فنی، رنگ‌بندی و موجودی هر محصول
- `FAMILY_TONES` — پالت رنگ‌بندی مشترک که در کارت‌ها و بخش نمونهٔ رایگان استفاده می‌شود
- `NUMERIC` — تعداد آجر در هر واحد، تعداد در هر پالت و وزن؛ ورودی محاسبه‌گر متراژ
- `PROJECTS` · `TESTIMONIALS` · `FAQS` · `TICKER` — گالری، نظرها، سوال‌های رایج و نوار متحرک

قیمت‌ها را به‌صورت عدد خام بنویسید (`1180000`)؛ تبدیل به رقم فارسی و جداکنندهٔ هزارگان
خودکار انجام می‌شود.

## قابلیت‌ها

- کاتالوگ با فیلتر دسته‌بندی و مرتب‌سازی (پیشنهاد کارخانه / ارزان‌ترین / گران‌ترین / الفبا)
- کارت محصول با تعویض تصویر، نورافکن دنبال‌کنندهٔ نشانگر و رنگ‌بندی قابل انتخاب
- مودال جزئیات با گالری تصاویر، جدول فنی و انتخاب مقدار
- **سبد خرید واقعی** با ذخیره در `localStorage` (با بستن مرورگر پاک نمی‌شود)
- محاسبه‌گر متراژ: مساحت خالص، تعداد آجر با ۷٪ پرت، تعداد پالت، وزن بار و برآورد هزینه
- فرم مشاوره و فرم ثبت سفارش با اعتبارسنجی شمارهٔ موبایل ایرانی
- لایت‌باکس پروژه‌ها، اسلایدر نظرها، آکاردئون سوال‌های رایج
- کاملاً واکنش‌گرا و سازگار با `prefers-reduced-motion`

> فرم‌ها و پرداخت به سروری وصل نیستند و فقط سمت کاربر شبیه‌سازی می‌شوند
> (شمارهٔ پیگیری نمایشی صادر می‌شود). برای اتصال واقعی، تابع‌های `submit` در
> `js/shop.js` → `initForms()` را به API خودتان وصل کنید.

## بازسازی تصاویر موقت

اگر خواستید تصاویر موقت را دوباره بسازید یا رنگ‌هایشان را عوض کنید:

```bash
pip install pillow
python3 tools/generate-placeholder-images.py
```

پس از رسیدن عکس‌های واقعی، این پوشه و اسکریپت را می‌توانید حذف کنید.
