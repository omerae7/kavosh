# Changelog

All notable changes to Kavosh are documented in this file.

## 1.0.0 — 2026-08-19

### Added

- a portable, evidence-first Agent Skill for multi-source research;
- five research groups with 20 functional roles;
- independent controls for research depth and evidence rigor;
- source selection, primary-source tracing, freshness, and citation rules;
- contradiction handling, red-team review, and explicit evidence states;
- quantitative, causal, comparative, scenario, and uncertainty guidance;
- installation guidance for ChatGPT, Codex, and Claude Code;
- a reproducible evaluation framework and prompt examples;
- a documented real-world portability case study;
- OpenAI interface metadata and project branding assets.
